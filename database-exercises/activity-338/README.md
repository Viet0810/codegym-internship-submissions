# Activity 338 - Xây dựng cơ sở dữ liệu quản lý sinh viên

Bài tập tạo cơ sở dữ liệu `student-management` với hai bảng:

- `Class(id, name)`
- `Teacher(id, name, age, country)`

## Chạy bài

Mở MySQL Workbench, mở file `student_management.sql`, sau đó chọn **Execute**.

Script tự tạo cơ sở dữ liệu, hai bảng, dữ liệu mẫu và truy vấn kiểm tra.
