# Servlet Exercises 470–474

- `/time`: thời gian hệ thống (470)
- `/login`: đăng nhập và lời chào (471), tài khoản mẫu `admin/123456`
- `/currency`: chuyển đổi USD sang VND (472)
- `/dictionary`: từ điển Anh–Việt (473)
- `/discount`: Product Discount Calculator (474)

Chạy bằng Java 17, Maven và Tomcat 10+.
